📖 Hướng dẫn nhanh
  1. Chọn tab Obfuscate, chọn ngôn ngữ (Python / Lua / JS / HTML).
  2. Dán code hoặc bấm Nạp file.
  3. Chọn Preset (Balanced / Compact / Deep / Unicode / Paranoid).
  4. (Tuỳ chọn) Bật Anti-tamper, đặt Expiry date, nhập tag tác giả.
  5. Bấm 🔐 OBFUSCATE NGAY (hoặc Ctrl+Enter).
  6. Copy / Tải file / Copy Data URI / Copy Markdown link.
🌐 Chạy HTML obf trên GitHub
  • GitHub Pages: bật Settings → Pages → Deploy from branch. File obf dùng iframe.srcdoc nên chạy mọi nơi.
  • Data URI: bấm "Copy Data URI" rồi dán vào thanh địa chỉ browser là chạy ngay.
  • Markdown link: bấm "Copy Markdown link" dán vào README GitHub → click là chạy.
  • htmlpreview.github.io: dán raw URL của file obf.
🛡️ Anti-tamper & Expiry
  • Anti-tamper: nhúng SHA-256 của code gốc. Nếu ai sửa file obf → tự raise lỗi, không chạy.
  • Expiry: chỉ chạy trước ngày X, sau đó raise SystemExit / throw.
  • Lưu ý: đây vẫn là obfuscate, không phải mã hoá bảo mật thật.
